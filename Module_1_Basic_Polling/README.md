# Module 1 – Basic Polling

## About this module

In this module, I started with the basic idea of a polling system. The program asks the user to enter a question and some options. Voters select their preferred option, and the program counts the votes.

## What the program does

1. Takes a poll question from the user.
2. Allows the user to enter 2 to 5 options.
3. Displays the options for voting.
4. Accepts votes and updates the count.
5. Shows the total votes, percentage for each option and the winner.

## Python concepts used

- `input()` and `print()`
- Variables and data types
- Lists and dictionaries
- `for` and `while` loops
- `if-else` conditions
- Basic calculations

## How to run

Open this folder in VS Code and run:

```bash
python program.py
```

## What I understood

This module helped me understand how user input, loops and conditions work together to make a simple voting program.
