# Online Polling System

Hi! This is my Python project for the programming lab. I made it to understand how a simple voting system works and how it can be improved step by step using Python.

I divided the project into four modules. Each module focuses on a different part of the polling system, starting with basic voting and moving towards saving the results in files.

## Project folders

- `Module_1_Basic_Polling` – creating a poll, voting and calculating results.
- `Module_2_Voter_Tracking` – keeping track of voters and avoiding duplicate votes.
- `Module_3_Modular_Design_Exception_Handling` – organizing the code into methods and handling invalid input.
- `Module_4_Data_Persistence_Statistics` – saving poll data and creating a report.

Every module has two files: `program.py` contains the Python code, and `README.md` explains what I have done in that module and how to run it.

## Tools and concepts used

- Python and VS Code
- Lists, dictionaries and sets
- Loops and conditional statements
- Functions, classes and methods
- Exception handling
- CSV and JSON file handling

No extra Python packages are required.

## How to run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the module you want to try.
4. Open its `program.py` file.
5. Open the VS Code terminal and run:

```bash
python program.py
```

Run each module separately. Module 4 creates a `poll_data` folder to store the results and report.

## What I learned

While making this project, I practised taking input from users, using loops and conditions, storing information in Python collections, checking invalid input, dividing a program into smaller methods, and saving data in files.

This project is made for learning and demonstration. The voter-name check is a basic duplicate check; it is not a secure real-world voter verification system.
